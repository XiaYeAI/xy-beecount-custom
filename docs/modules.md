# 交易页月度工作台模块清单

## 1. 月份与日期工具（先行）

- 职责：解析 `YYYY-MM`，生成月度半开区间，计算目标月同日或月末日期。
- 依赖：无。
- 改动范围：`frontend/apps/web/src/lib/` 与对应单元测试。
- 验收：覆盖跨年、闰年二月、31 日落月末。

## 2. API 客户端批量复制契约

- 职责：扩展已有批量创建客户端类型，完整承载复制所需币种字段和幂等键。
- 依赖：模块 1 的目标日期结果。
- 改动范围：`frontend/packages/api-client/src/ai.ts` 或专用写入客户端模块，及导出入口。
- 验收：请求体使用既有 batch-create 路由，人工复制明确关闭 AI 标签。

## 3. 交易页月度状态与摘要

- 职责：管理月份、派生交易筛选日期、加载 analytics 与预算使用量、渲染紧凑统计条。
- 依赖：模块 1。
- 改动范围：`TransactionsPage.tsx`，必要时新增小型展示组件和 i18n 文案。
- 验收：切月时列表与四项统计同时指向同一月份；无预算时显示空态。

## 4. 批量复制对话框与工具栏接线

- 职责：在既有选择工具栏增加复制操作、目标月份确认框、加载/成功/失败反馈。
- 依赖：模块 1、模块 2、模块 3。
- 改动范围：`SelectionToolbar.tsx`、新对话框组件、`TransactionsPage.tsx`、i18n 和单元测试。
- 验收：复制字段正确、日期裁剪正确、最多 50 笔、重复点击受阻、失败后选中项保留。

## 5. 集成与界面验证

- 职责：通过类型检查、单元测试、生产构建和实际浏览器渲染验证整个流程。
- 依赖：模块 1-4。
- 改动范围：测试及 `docs/manual-verification.md`。
- 验收：执行“选月 → 选中 → 复制到下月 → 刷新确认”的端到端路径。
