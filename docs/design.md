# 交易页月度工作台与批量复制设计

## 目标与范围

本改造只覆盖 Web 端的 `/app/transactions`：

1. 以显式月份选择器替代“进入筛选弹窗后填写起止日”的高频操作。
2. 在交易页展示所选月的收入、支出、月度结余和预算剩余。
3. 复用已有批量选择能力，将所选交易复制到指定月份（默认下月）的相同日期。

不实现周期账单；不改 iOS；不改 BeeCount Cloud 的同步实体、账本数据结构或数据库迁移。

## 已确认的事实

- 交易查询已支持 `date_from` / `date_to` 半开区间过滤。
- 交易页已有桌面端批量选择、导出和删除。
- `POST /write/ledgers/{ledger_id}/transactions/batch` 已支持一次创建最多 50 笔交易，并会产生同步变更及 WebSocket 通知。
- `/read/workspace/analytics` 可读所选账本的收入、支出与结余；预算使用量已有读取接口。

## 交互与数据结构

### 月份状态

新增前端状态 `selectedMonth: string`，格式固定为 `YYYY-MM`。

- 初始值：用户本地时区下的当前月。
- 选择某月时，派生出 `dateFrom`（当月 1 日）和 `dateTo`（下月 1 日），覆盖交易请求中的日期范围。
- “上月”“本月”“下月”只改变 `selectedMonth`。
- 高级筛选弹窗仍可用；月度选择器是交易页的日期范围权威来源，切月时清空原有的手动起止日期，避免两套日期条件冲突。

### 月度摘要

```ts
type MonthSummary = {
  income: number
  expense: number
  balance: number // income - expense
  budgetRemaining: number | null // 无已启用预算时为 null
}
```

- `income`、`expense`、`balance` 从既有 analytics 月度请求读取，并显式使用自然月口径，和交易列表的公历月份过滤一致。
- `budgetRemaining` 为当前账本所有已启用月度预算的 `amount - used` 汇总；没有预算时 UI 显示“未设置预算”，不伪造 `0`。
- 既有 `GET /read/ledgers/{id}/budgets/usage` 新增可选 `period=YYYY-MM`、`tz_offset_minutes` 和 `natural_month` 查询参数，使历史月份的预算用量与该月统计一致；缺省参数保持原来的“当前周期”行为。
- 金额沿用当前账本本位币与已有金额格式化函数。

### 批量复制请求模型

```ts
type CopyTarget = {
  month: string // YYYY-MM
  preserveTime: true
}
```

复制对每一条已选交易构造已有 `BatchTxItem`：

- 保留：收支类型、金额、账户/转账账户、分类、标签、备注、币种、折算金额、交易时间中的时分秒。
- 修改：`happened_at` 的年/月替换为目标月；日取 `min(原日, 目标月最后一天)`。
- 不复制：附件。附件常包含一次性凭证，重复复制会产生误导性账单。
- 目标月份默认等于 `selectedMonth` 的下一个月，用户可在确认框改选。

前端调用既有 `batchCreateTransactions`，固定传 `autoAiTag: false`，不向人工复制的账单添加“AI记账”标签。每次请求最多 50 笔；超过时在确认前阻止操作并提示先分批复制。

## 核心流程

1. 用户改变月份，交易列表按该月刷新；月度摘要和预算剩余并行刷新。
2. 用户进入批量选择并选中交易，工具栏新增“复制到下月”。
3. 用户点击复制，打开确认框：目标月、源账单数、生成日期预览及“31 日调整为月末”的提示均可见。
4. 确认后，按钮立即进入加载态并禁用其余批量操作，调用 batch-create。
5. 成功后退出选择模式、刷新当前月列表与摘要，并提示“已复制 N 笔到 YYYY 年 MM 月”。
6. 失败后保留选择状态，显示“复制失败 + 服务端原因 + 下一步建议”，允许用户修正后重试。

## 边界与并发

- 空选择：复制按钮禁用。
- 目标月份与源月份相同：允许，但确认框必须明确提醒会新建重复账单；默认目标始终为下月。
- 2 月与短月：29/30/31 日自动落到该月最后一天。
- 多币种与转账：透传已有币种、账户和转账字段；不重新计算历史折算金额。
- 无写权限：不展示复制入口，和现有批量操作权限保持一致。
- 双击/慢网络：复制请求期间使用 `saving` 状态防重复提交；复用请求幂等键。
- 冲突、权限和网络错误：透出服务端可读摘要，并给出“刷新列表后重试”或“确认账本写权限”的建议。

## 视觉方向

采用“高密度账本工作台”而非首页仪表盘：顶部为月份导航与四项小型统计条；检索、筛选、导出及批量操作维持一行。强调数字层级、紧凑留白和明确的操作状态，兼容原有浅色/深色主题与移动端布局。

## 假设与非目标

- “剩余金额”按用户确认同时呈现“本月结余”和“预算剩余”。
- 首版只提供桌面端批量复制，和既有桌面端多选入口一致。
- 首版不跨分页选择；用户可按页分批复制，单次上限 50 笔。
