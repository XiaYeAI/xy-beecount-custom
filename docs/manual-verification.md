# 交易页月度工作台人工验收

| 验证步骤 | 预期结果 | 结果 | 备注 |
| --- | --- | --- | --- |
| 打开交易页，选择任意历史月份，再点上月/下月/本月 | 列表与收入、支出、结余、预算剩余同步切换到该自然月 | ⬜ | |
| 选择无预算的月份 | “预算剩余”显示“未设置预算”，而不是 0 | ⬜ | |
| 进入批量选择，选中 1-50 笔交易，点击“复制到下月” | 弹窗展示目标月份、笔数、短月调整说明；未选中时按钮不可用 | ⬜ | |
| 复制一笔 31 日的交易到 2 月 | 新账单落在 2 月最后一天，原交易及附件均不变 | ⬜ | |
| 复制后刷新 Web 并在 iOS 同步页检查 | Web 显示新交易，iOS 收到新增交易；新交易没有自动加“AI记账”标签 | ⬜ | |
| 断网或临时取消写权限后复制 | 按钮有加载态且不会重复创建；失败提示说明原因并提示刷新/检查权限，选中项仍保留 | ⬜ | |
