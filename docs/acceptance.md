# 交易页月度工作台验收标准

## 总体验收

1. 交易页顶部可直接选择月份，并有上月、本月、下月操作；选择 2026-02 时列表请求范围为 `[2026-02-01, 2026-03-01)`。（自动化）
2. 月份切换后，交易列表、本月收入、支出、结余和预算剩余均使用同一账本与同一月份。（自动化 + 人工）
3. 无预算时，预算剩余显示“未设置预算”，不显示误导性的金额 0。（自动化 + 人工）
4. 每个超过 1 秒的批量复制操作在 200ms 内显示加载状态并禁用重复操作。（人工）
5. 复制失败提示包含：复制失败的操作、服务端或网络原因、下一步建议。（自动化 + 人工）

## 月份工具模块

1. 月份区间覆盖月份第一天，排除下月第一天。（自动化）
2. 2026-01-31 复制至 2026-02 的日期为 2026-02-28；2024-01-31 复制至 2024-02 的日期为 2024-02-29。（自动化）
3. 复制后的交易保留原始时分秒。（自动化）

## 批量复制模块

1. 选中 1-50 笔交易后，“复制到下月”可用；未选中时不可用。（自动化 + 人工）
2. 确认框默认目标为当前所选月的下一个月，并展示目标月份、笔数及短月日期调整提示。（人工）
3. 请求使用已有 batch-create 接口，`auto_ai_tag=false`；保留业务字段，且不发送附件。（自动化）
4. 复制成功后提示新建笔数，退出选择状态并刷新列表/摘要。（自动化 + 人工）
5. 选中超过 50 笔时不得发请求，并提示用户分批复制。（自动化 + 人工）
6. 请求失败时选中状态不丢失，用户能直接重试。（自动化 + 人工）
